# 🏭 Sistema de Mantenimiento Predictivo - Industria Azucarera Cubana

## 📋 Descripción del Proyecto

Sistema inteligente de mantenimiento predictivo desarrollado para la industria azucarera cubana, diseñado para optimizar la gestión de equipos críticos ante las condiciones de escasez de repuestos y combustibles características del contexto cubano.

### 🎯 Problemática

La industria azucarera cubana enfrenta desafíos únicos:
- **Escasez de repuestos**: Dificulta el mantenimiento correctivo tradicional
- **Calidad variable del combustible**: Afecta el rendimiento de equipos
- **Equipos envejecidos**: Mayor propensión a fallas
- **Limitaciones de combustible**: Restricciones operativas frecuentes

### 💡 Solución Propuesta

Implementación de un modelo de **Aprendizaje Automático Supervisado** (Random Forest) que predice la probabilidad de fallas en equipos azucareros, permitiendo:
- Mantenimiento preventivo optimizado
- Reducción de paradas no planificadas
- Mejor gestión de inventario de repuestos limitados
- Extensión de vida útil de equipos

## 🛠️ Tecnologías Utilizadas

- **Python 3.8+**
- **scikit-learn**: Modelo de aprendizaje automático
- **Streamlit**: Interfaz web interactiva
- **pandas/numpy**: Procesamiento de datos
- **matplotlib/seaborn**: Visualización de resultados
